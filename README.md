Quasar Datapack
---------------

just note this repo is a bit empty because we had to basically scrap the entire datapack awhile ago and everyone who works on quasar has to deal with either school or work.

This project is a collection of systems, tools, and experiments built to push
vanilla Minecraft farther than usual datapacks allow. The goal is to create
a framework that can support machines, structure validation, visual debugging,
and other advanced mechanics without requiring mods.

The pack is organized into modules. Each module handles one part of the system:
core utilities, machine logic, block state checks, visual outlines, and more.
Everything is written to be reusable and easy to extend.

Most files follow a consistent structure so development stays predictable.
Functions are grouped by purpose, and storage is used for passing data between
systems. Visual elements like particles and block displays are kept separate
from logic so they can be swapped or updated without breaking anything.

This repository will grow as new systems are added. Some parts are experimental
and may change as the project evolves. Contributions and improvements are
welcome, especially for organization, performance, and clarity.

To install, place the datapack folder into a world's datapacks directory and
reload the world. Make sure the resource pack is active if the system requires
custom textures or remapped blocks.

This project is still in active development.
